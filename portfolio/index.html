Concurrency Bahn — Zone-parallel railway simulation

Rust · Threads · Message passing

Team project: a railway simulation split across threads, with no locks and the same output as the sequential reference.

  • Parallelised a railway simulation in Rust with one thread per zone, so regions of the network run at the same time.
  • Threads coordinate only by message passing over channels: no locks, no shared mutable state; each thread owns its zone's data.
  • Designed the synchronisation and shutdown protocol so results always match the sequential version; added an AI-assisted interactive visualization (linked below).
